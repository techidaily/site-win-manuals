## Latest DJ Software Version 3.7.5.1 Release for Pioneer CDJ 3000 Re2 & Le4 Models

[![Version 3.7.5.1 update for PCDJ DJ Software](https://i1.wp.com/pcdj.com/wp-content/uploads/2016/12/dex3redex3le3751update-cover.jpg?resize=706%2C321&ssl=1)](https://i1.wp.com/pcdj.com/wp-content/uploads/2016/12/dex3redex3le3751update-cover.jpg?fit=706%2C360&ssl=1 "Version 3.7.5.1 update for PCDJ DJ Software")

**Download maintenance release version 3.7.5.1 for DEX 3 RE or DEX 3 LE DJ mixing software**

A new update has been posted below for both DEX 3 RE ([Red Edition of DEX 3](https://tools.techidaily.com/pcdj/products/)) and DEX 3 LE ([Free DJ software version](https://tools.techidaily.com/pcdj/products/)). Version 3.7.5.1 is a maintenance update and free for all existing users.

[LEARN MORE ABOUT DEX 3 RE ![DEX 3 RE Screen Shot Large](https://i0.wp.com/pcdj.com/wp-content/uploads/2014/06/dex3re-screenshot.png?fit=300%2C169&ssl=1 "DEX 3 RE Screen Shot Large")](https://tools.techidaily.com/pcdj/products/)

A ‘maintenance release’ basically means there isn’t new functionality present in the 3.7.5.1 DJ software versions, but rather performance improvements and bug fixes for existing features. In particular, version 3.7.5.1 for both [DEX 3 RE](https://tools.techidaily.com/pcdj/products/) and [DEX 3 LE](https://tools.techidaily.com/pcdj/products/) DJ programs have been updated to include the latest [Pulselocker](https://tools.techidaily.com/pcdj/products/) SDK — improving performance of the DJ-centric music subscription platform in both applications.

[LEARN MORE ABOUT OUR FREE DJ SOFTWARE ![DEX 3 LE DJ software interface](https://i0.wp.com/pcdj.com/wp-content/uploads/2016/10/dex3-slam-dunks.jpg?fit=300%2C169&ssl=1 "DEX 3 LE DJ software interface")](https://tools.techidaily.com/pcdj/products/)

One bug that we’ve taken the collective boot to was an random issue that would occur for some subscribers when streaming songs from the [Pulselocker](https://tools.techidaily.com/pcdj/products/) platform. Songs would time out or or suggest they were unavailable to stream upon loading to a deck, although DJs could download the tracks for offline playback without issue. The streaming issue is resolved, and users of [DEX 3 RE](https://tools.techidaily.com/pcdj/products/) and [DEX 3 LE](https://tools.techidaily.com/pcdj/products/) can stream tracks from Pulselocker’s massive 44 million song catalog with up utmost confidence this holiday season.

Version 3.8 is on the way soon with a slew of new features that our users are really going to enjoy. In the meantime we highly suggest you update to version 3.7.5.1 for your respective DJ software version below, especially if you’re a [Pulselocker](https://tools.techidaily.com/pcdj/products/) user.

#### Changes In Version 3.7.5.1 For DEX 3 RE and DEX 3 LE

* Updated to include the latest Pulselocker SDK (fixes random streaming issue reported by some subscribers)
* Minor bug fixes and performance improvements
